# E-commerce App

A React + TypeScript e-commerce app with Tailwind CSS and Zustand for state management.

## Stack

- **React 18** + **TypeScript**
- **Vite** – build tool
- **Tailwind CSS** – styling
- **Zustand** – cart state
- **React Router** – navigation

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

- `npm run dev` – start dev server
- `npm run build` – production build
- `npm run preview` – preview production build

## Features

- Product listing (home)
- Product detail with add-to-cart and quantity
- Cart with update/remove and subtotal
- Checkout form (contact, shipping, payment) and order confirmation
